# ST.JOHN v2.1 Simulation (`stjohn-v2-sim`)

> **一句话简介**：用多 Agent + LangGraph 模拟 ST.JOHN 日咖夜酒社交小程序在三亚、上海、成都三城冷启动 90 天的生死演化，供产品负责人与门店投资决策者在重资产开店前低成本验证留存、利润回本与裂变杠杆，**模拟跑出三亚爆款（30日留存 19.84% / 90天经营净利 ¥415,084 / 装修回本 69.2%，模拟）、上海活下来（30日留存 11.64% / 第3月单月转正 +¥21,200 / 90天累计净利 ¥-49,768，模拟）、成都危在旦夕（30日留存 3.88% / 90天累计净利 ¥-116,432，模拟），全套 39 次 LLM API 调用总成本仅 ¥0.01977 元（模拟）。**

## ⚠️ 数据性质与合规声明

- **全部数字均为【模拟】**：本仓库产出的所有到店人数、留存率、营收、净利润、回本率、裂变系数 K 及抽样用户发帖均为多 Agent 规则引擎 + LLM 模拟推演结果，**严禁写成或当成真实用户、真实留存、真实利润**。
- **固定随机种子 100% 可复现**：`GLOBAL_SEED = 20261220`，连续重跑两次 270 条城市日度记录与决策日志分毫不差。
- **参数透明分层**：严格区分【实测】（v1 真机菜单/价格/19:00切换/送Shot规则/九神阵营比例）、【估算】（三城房租/减薪20%后人工/装修/容量上限）、【假设】（初始转化率/裂变系数/1月寒潮冷周）。

## 🏗️ 多 Agent × LangGraph 架构

神 / 派系不做 Agent，只做用户数据。系统由 **9 个 Agent 角色** 在 `LangGraph` 状态图中驱动 90 天日夜双步循环（白天一步算咖啡、晚上一步算夜酒）：

1. **总调度 Agent × 1**：每天发指令、汇总三城、每周学习决策与写周报、第 30 / 60 / 90 天判生死、审计参数有没有被人为调好看。
2. **城市 Agent × 3**：
   - **成都（东门大桥）**：房租 2.2万/月、人工 3.6万/月、装修 50万；天堂30 / 人间45 / 地狱25。
   - **上海（INS 附近）**：房租 5.0万/月、人工 4.8万/月、装修 80万；天堂25 / 人间35 / 地狱40。
   - **三亚（亚龙湾）**：房租 3.0万/月、人工 3.84万/月、装修 60万；天堂50 / 人间35 / 地狱15（本地:游客 = 1:9，游客平均待 4 天，按行程内复访 + 离开后推荐算）。
3. **杠杆 Agent × 3**：
   - **社交裂变 Agent**：九神测评解锁 8 款隐藏特调、点特调送同款免费 Shot（仅限送人，凌晨5点过期）、半价送酒、星云雷达配对解锁 10 句限额聊天。
   - **线上口碑 Agent**：满意用户（>=4分）30% 发小红书 / 抖音，1 条笔记 7 天内带来 0.5 个新到店。
   - **价格 / 复购 Agent**：每周根据容量满载率与留存反馈动态学习调价与主题促活策略，留存完整决策日志。
4. **检查 Agent × 2**：
   - **评测 Agent**：严格校验容量红线（白天 <=120人、晚上 <=90人、单日 <=210人）、`收入 = 人数 × 均价`、`0 <= 留存 <= 100%`，违规立即报错停机。
   - **成本 Agent**：精确记录 DeepSeek / Qwen API 每次调用的 Token 与人民币花费（共 39 次调用，总计 `¥0.01979` 元，不到 2 分钱）。
